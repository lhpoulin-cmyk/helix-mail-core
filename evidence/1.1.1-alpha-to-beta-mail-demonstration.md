## Independent review

Each replacement demonstration generated a unique non-secret correlation
identifier on the originating physical client. Every machine authenticated
through trusted TLS, submitted to Admin, received an Admin reply, and retrieved
it through trusted IMAPS. Admin and Cluster Admin each sent to every required
machine, retrieved the machine replies, and exchanged mail with each other in
both directions. Message bodies and identifiers are not committed.

The RCPT matrix accepted both administrative identities to all seven machine
mailboxes, including the two deferred machines. It accepted machine-originated
mail to both administrative mailboxes. It rejected `hv-lore -> hv-katra`,
`ws-matriarch -> ws-hadrian`, and `test-sender` to representative `hv-*` and
`ws-*` recipients with SMTP 550 before DATA. A machine credential attempting
the Admin envelope sender was rejected with SMTP 501. The canonical hyphenated
`cluster-admin@home.arpa` was used; no underscore identity was created.

external recipients were rejected before DATA. Independent live review found
